# FSM-Based-Hybrid-Memory-Testing-using-Verilog-HDL
This project implements an FSM-based hybrid memory testing system using Verilog HDL, combining March C− and Checkerboard algorithms to detect memory faults such as stuck-at, transition, and coupling faults. It includes memory models, FSM controllers, fault injection, and testbench verification for reliable memory testing on FPGA platforms.
